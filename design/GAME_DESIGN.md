# THE OTHER SIDE — GAME DESIGN

## 1. Design Goal

THE OTHER SIDE is a psychological horror game centered on behavioral prediction.

The primary skill is understanding systems and behavior.

## 2. Core Verbs

**Explore → Observe → Inspect → Investigate → Infer → Test → Hide → Manipulate → Deceive → Adapt → Escape**

## 3. Core Loop

**Explore → Observe → Investigate → Hypothesize → Test → Mirror Adapts → Deceive → Mirror Counter-Tests → Discover Information Outside Its Model → Exploit → Escape**

## 4. Progression

Act I asks how to avoid the Mirror.

Act II asks how the Mirror knows.

Act III asks what the Mirror cannot correctly know or interpret.

## 5. Deception

A successful deception:

1. causes the Mirror to commit toward an incorrect expectation;
2. creates a temporary opening;
3. produces observable consequences;
4. lets the player infer the expectation;
5. teaches the Mirror something afterward.

No deception is a permanent exploit.

## 6. Prediction

Prediction is never arbitrary.

The Mirror predicts from:

- observed routes;
- timing;
- repeated choices;
- system interactions;
- known access;
- contextual behavior.

The exact prediction algorithm is implementation-level.

## 7. Counter-Testing

The Mirror can deliberately create situations that test Shamshir's:

- trust;
- risk tolerance;
- route preferences;
- response to uncertainty;
- willingness to repeat behavior.

These tests must use Rosslyn's real infrastructure.

## 8. Overfitting

Late in the game the Mirror becomes sophisticated enough to expect layered deception.

Its sophistication becomes a weakness.

The final error is not random stupidity. It is an incorrect interpretation produced by an overcomplicated model.

The Mirror can observe physical actions without necessarily assigning them the correct strategic meaning.

## 9. Final Strategy

Shamshir's final strategy combines:

1. knowledge obtained from the previous technician's trail;
2. understanding of how the Mirror predicts behavior;
3. information acquired outside the Mirror's complete observation;
4. deliberate violation of the Mirror's overfit expectation.

The legacy vulnerability is real and pre-existing.

The Mirror's failure creates a temporary opening.

Shamshir uses that opening to exploit the legacy vulnerability and enter the canonical B-2 escape route.

The exact hardware interaction remains implementation-level.

## 10. Combat

There is no conventional combat.

The environment is the player's defensive and strategic tool.

## 11. Failure

Failure represents successful containment/interception.

The presentation remains non-graphic.

Reload restores the exact saved state, including the Mirror's behavioral state.

## 12. Player Agency

The player must be able to:

- test theories;
- make mistakes;
- choose routes;
- interpret evidence;
- discover patterns;
- deliberately vary behavior;
- deceive the Mirror;
- exploit information asymmetry.

The game must not replace deduction with automatic conclusions.

## 13. Final Escape

The frozen route is:

**VC-01 → R-401 → C-403 → R-402 → R-403 → C-499 → Exterior**

C-499 is the genuinely unmonitored final transition.

The escape is causal rather than lucky:

**technician knowledge + Mirror understanding + information asymmetry + deliberate pattern violation → incorrect prediction → temporary opening → legacy vulnerability → escape**

The Mirror survives.
