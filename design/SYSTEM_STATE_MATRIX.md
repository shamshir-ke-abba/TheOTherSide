# THE OTHER SIDE — SYSTEM STATE MATRIX

**Status:** LOCKED DESIGN FRAMEWORK

## 1. Principle

**Architecture stays stable. System state changes.**

A revisit should create tension through changed rules, not arbitrary remodelling.

## 3. Access States

Door states should be causally tied to infrastructure.

Possible states:

- unlocked;
- controlled;
- restricted;
- fail-safe;
- fail-secure;
- mechanically bypassable.

Electronic access must trace to a real parent system.

Exact hardware is implementation-level.

## 4. Surveillance States

Surveillance is spatial, not magical.

Every observation point has:

- physical position;
- field of view;
- occlusion;
- acoustic relationship;
- system connectivity.

Blind spots are created by real architectural or infrastructure boundaries.

Exact camera/sensor models are implementation-level.

## 5. Lighting

Lighting is both atmosphere and information.

Early:

- stable institutional lighting.

Middle:

- selected circuits change;
- emergency systems become visible;
- player learns that lighting states have causes.

Late:

- lighting becomes part of route and observation manipulation.

## 6. Acoustic State

Acoustic relationships follow architecture.

A room can be:

- acoustically exposed;
- partially isolated;
- mechanically noisy;
- acoustically ambiguous;
- genuinely isolated.

Sound must not become an arbitrary detection meter.

## 7. Infrastructure State

Rosslyn contains mixed generations of infrastructure.

The important design fact is coexistence between modern integrated systems and older legacy/pre-digital systems.

No unsupported numerical percentage or historical date is part of the canon.

The coexistence is functional, not decorative.

Legacy systems are important because they can have different information and control properties from newer integrated systems.

## 8. Mirror Intervention

The Mirror does not simply toggle hazards because the player presses a button.

Intervention must be based on:

- observed behavior;
- learned expectation;
- available infrastructure;
- current system state.

Every meaningful intervention must remain consistent with:

**Observed data → learned pattern → contextual prediction → intervention**

The exact intervention and runtime algorithm remain implementation-level.

## 10. Systemic Escalation Rule

Each Act should increase the consequences of being predictable.

Act I teaches that Rosslyn reacts.

Act II teaches why.

Act III makes the player's accumulated understanding necessary for escape.
