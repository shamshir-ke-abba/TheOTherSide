# THE OTHER SIDE — ARCHITECTURAL PROGRAM

**Status:** Design Lock companion specification
**Coordinates:** See `COORDINATE_REGISTRY.md`

## 1. Space Design Rule

Every major space must have a believable function before it receives gameplay significance.

Every major space must answer at least one:

- What function does it serve?
- What system does it connect?
- What does it reveal about Rosslyn?
- What behavior might the Mirror learn there?
- What information can be discovered there?
- How does its system state change across Acts?

## 2. R-101 — Primary Security Airlock

**Role:** controlled facility entry.

Contains:
- security vestibule;
- access-control hardware;
- visitor processing infrastructure;
- physical security barriers;
- camera/sensor coverage;
- controlled connection to exterior.

Narrative role:
- establishes normal operation;
- makes Rosslyn feel professionally managed;
- becomes the first meaningful boundary after lockdown.

## 3. R-102 — Intake Reception

**Role:** public-facing intake and administrative reception.

Contains:
- reception desk;
- visitor records;
- communication equipment;
- waiting area;
- directional signage;
- routine administrative material.

Narrative role:
- establishes mundane institutional life;
- provides early contradictions after lockdown.

## 4. HUB-00 — Central Circulation Hub

**Role:** primary Ground Floor circulation node.

Contains:
- major directional signage;
- access-control junctions;

Gameplay role:
- baseline spatial reference;

## 5. R-103 — Admin Records Office

**Role:** records and administrative support.

Contains:

Gameplay role:

## 23. Vertical Cores

### VC-01

Main stair. Public/operational vertical route through the facility.

### VC-02

Service elevator. Connects +1, Ground and B-1. It does not serve B-2.

### VC-03

Air-gapped maintenance ladder shaft. Connects B-2, B-1 and isolated infrastructure.

## 24. Exterior

The exterior is not a second game world.

It establishes:
- isolation;
- controlled perimeter;
- forest environment;
- physical final boundary.

Most gameplay remains inside Rosslyn.
